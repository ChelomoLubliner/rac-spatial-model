# T3 visual evidence and probes

QA files of plan task T3 (new data preparation and pixel calibration; T3-newdata). Written by `contour_algorithm.calibrate_pixels`, `contour_algorithm.shoe_quality` and `contour_algorithm.qa_sheets` (paths from the profile's `prep` entry, decision A-090); exact commands and outputs in `docs/tests/T3-new-data-results.md`. Every image below was opened with the Read tool on 2026-11-06 by the agent who made it (user rule 10).

## Files

| File | What it is |
|---|---|
| `old/pixel_calibration.csv`, `../../../processed_data/new/pixel_calibration_new.csv` | Calibration summary (`section, name, value`): meta, the named settings (legacy, optima, best offsets at 300, the four orientations, the 2023 R script values, the 2023 `COL/ROW` for NEW) with hits, strict and dilated rates, mean distance to contact; the 200 bootstrap draws of Delta and their interval; the conditions of A-086; NEW also the rule and its decision |
| `old/calibration_grid.csv`, `new/calibration_grid_new.csv` | Stages O, C, F of A-086 for both criteria: one row per (orientation, sx, sy) with its best offsets, best first within each block |
| `old/shoe_contact.csv`, `new/shoe_contact_new.csv` | Per-shoe table (all shoes, shoes without RACs included): RACs, contact pixels, strict and dilated on-contact counts and rates, best shift within +-4 px, best flip rate, all-off flags (A-089) |
| `old/calibration_curves.png`, `new/calibration_curves_new.png` | Calibration grid profiles (see below) |
| `old/offcontact_shoes.png`, `new/offcontact_shoes_new.png` | The 24 shoes with the lowest strict on-contact rate (and every shoe whose RACs are all off contact), RACs as hollow squares: green on a contact pixel, red off it |
| `new/raw_sheet_01_new.png` ... `raw_sheet_20_new.png` | Every NEW shoe (32 per sheet, 1-based ids in the labels): the raw contact record (white) and its RACs by the profile's mapping (green on contact, red off); label: n RACs, strict rate, contact pixels |
| `new/visual_flags_new.csv` | What was noted while looking at the 20 raw sheets (`shoe, flag, note`; flags `frame_artefact`, `partial_or_faint`, `image_type`, `margin_debris`, `rac_off_print`, `over_inked`). Seen at sheet resolution, one shoe per tile; **not the census** of plan T3 step 3, which reviews every shoe at full size; the `over_inked` and `partial_or_faint` lists are examples, not exhaustive |
| `probes/t3_cross_eval.py`, `.out` | Post-hoc (not pre-registered) cross-check for A-087: each dataset at the other's optimum, with shoe-bootstrap intervals |
